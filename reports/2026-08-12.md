## Featured: Agent Worktree Isolation (`isolation: "worktree"`)

When you spawn subagents via the `Agent` tool or inside Workflows, they share the same working directory by default. If multiple agents edit the same files in parallel, they'll conflict. The `isolation: "worktree"` parameter solves this by giving each agent a temporary git worktree — a full, isolated copy of the repo.

**Why it's useful:** Enables safe parallel file mutations. One agent can refactor `auth.ts` while another rewrites `api.ts` without merge conflicts. The worktree is automatically cleaned up if the agent makes no changes; otherwise the path and branch are returned so you can merge.

**Quick example (Agent tool):**
```
Agent({
  description: "Refactor auth module",
  prompt: "Refactor src/auth.ts to use the new session API...",
  isolation: "worktree"
})
```

**In Workflows:**
```js
const results = await pipeline(
  files,
  (file) => agent(`Migrate ${file} to the new API`, {
    isolation: 'worktree',
    label: `migrate:${file}`
  })
)
```

**Tradeoffs:** Worktree setup costs ~200-500ms + disk per agent, so only use it when agents actually mutate files in parallel. For read-only research agents, skip it.
