## Featured: Easel (Built-In Mod)

**Easel** is a new built-in mod shipped in Claude Code v2.1.330 (Nov 20) that draws charts and visualizations on request directly in your coding session.

**What it is:** A built-in mod (like "You Should Know") that Claude uses automatically when you ask for a chart, graph, or data visualization during a session. It renders charts inline without requiring you to set up external plotting libraries or leave your terminal.

**Why it's useful:** When debugging, exploring data, or reviewing metrics, you often want a quick visual. Instead of writing a matplotlib script or opening a separate tool, you can just ask Claude to chart something and Easel handles the rendering. It pairs well with the `/dataviz` skill for design guidance.

**Quick usage:**
```
> Show me a chart of the error rates from the last 7 days of logs

# Claude uses Easel to render an inline chart automatically

# To turn off automatic charts:
> /config
# Navigate to Easel settings and disable automatic mode
```

**Configuration:** Automatic chart drawing can be toggled off in `/config` if you prefer to only use it on demand.
