## Featured: `ReportFindings` Tool (Structured Code Review Output)

The `ReportFindings` tool lets Claude Code emit code-review results as a typed, structured list instead of free-form text. When used with `/code-review`, findings are rendered in the host UI (terminal, VS Code, desktop app) as a ranked, actionable list with file, line, category, severity, and failure scenario for each item.

**Why it's useful:** Review findings become machine-readable — IDEs can jump to the exact line, CI integrations can parse results programmatically, and re-reporting after fixes tracks which findings were fixed vs. skipped.

**Quick example:**
```
/code-review --fix
```
Claude reviews the diff, calls `ReportFindings` with a structured array of verified findings (most severe first), then applies fixes. After fixing, it re-reports with `outcome` set on each finding (`"fixed"`, `"skipped"`, or `"no_change_needed"`).

The tool was introduced in v2.1.196 (June 29) and is used automatically by the `/code-review` skill — no manual invocation needed.
