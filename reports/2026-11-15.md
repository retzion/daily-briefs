## Featured: Code Mode (v2.1.323)

Code Mode is a new experimental feature in Claude Code v2.1.323 that changes how Claude orchestrates tool calls. Instead of making individual tool calls one at a time, Claude writes a JavaScript program that calls its tools programmatically — enabling loops, conditionals, and parallel execution in a single turn.

**Why it matters:** Complex tasks often require many sequential tool calls (search, read, edit, test, repeat). Code Mode lets Claude express that entire workflow as code, reducing round-trips and enabling patterns like "find all files matching X, read each one, and apply the same edit" in one shot.

**Usage:**

```bash
# Enable in settings
claude config set experimental.codeMode true

# Or toggle per-session
/config experimental.codeMode=true
```

When enabled, Claude may respond with a JavaScript block that calls tools like `glob()`, `read()`, `edit()`, and `bash()` as functions. The runtime executes the script and returns results.

**Note:** This is experimental and can be disabled org-wide via managed settings (`experimental.codeMode: false`). Watch for unexpected behavior and report issues.
