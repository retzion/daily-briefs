## Featured: `CLAUDE_CODE_DISABLE_FILE_MENTIONS`

A new environment variable added in the Oct 14 changelog that changes how `@` file mentions work in Claude Code.

**What it does:** By default, when you use `@filename` in a prompt, Claude Code inlines the entire file contents into your message. With this env var enabled, Claude instead receives just the file path and reads the file itself using its file tools.

**Why it matters:** For large codebases, inlining big files into every prompt burns context window tokens fast. This setting lets Claude decide how much of a file to read, keeping more room for reasoning and multi-file work.

**Usage:**
```bash
# In your shell
export CLAUDE_CODE_DISABLE_FILE_MENTIONS=1
claude

# Or in settings.json
{
  "env": {
    "CLAUDE_CODE_DISABLE_FILE_MENTIONS": "1"
  }
}
```

Particularly useful when referencing large config files, generated code, or data files where Claude only needs specific sections.
