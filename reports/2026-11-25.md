## Featured: MCP Server Skills (Beta)

Claude Code v2.1.332 introduces **skills from MCP servers** — a beta feature that lets MCP servers expose slash commands directly in Claude Code's skill menu. Previously, MCP servers could only provide tools (functions Claude calls) and resources (data Claude reads). Now they can also publish structured workflows as skills.

**Why it matters:** This bridges the gap between MCP's tool-centric model and Claude Code's skill system. Teams can package complex workflows (deploy pipelines, review checklists, migration steps) as MCP-hosted skills that any Claude Code user connecting to that server gets automatically.

**Quick usage:**
```jsonc
// In .claude/settings.json — connect to an MCP server that exposes skills
{
  "mcpServers": {
    "team-workflows": {
      "command": "npx",
      "args": ["@myorg/team-mcp-server"],
      "alwaysLoad": true
    }
  }
}
```
Once connected, the server's skills appear in the `/` menu alongside built-in skills. Invoke them like any other: `/deploy-staging`, `/run-migration`, etc.

**Trade-off:** Beta feature — the skill protocol between MCP servers and Claude Code may change. Skills from MCP servers run with the same permissions as the server's tools, so vet servers carefully before connecting.
