## Featured: `/docx` Skill (Word Document Operations)

The `/docx` skill lets you create, read, edit, and manipulate Microsoft Word documents (`.docx`, `.dotx`) directly from Claude Code. It triggers any time a `.docx` file is involved — as input, output, or both.

**Why it's useful:** Many professional workflows still require Word format — contracts, proposals, reports, specs. Instead of context-switching to Word, you can generate polished documents from code, data, or conversation context without leaving your terminal.

**Quick usage examples:**

```
# Create a document from scratch
> /docx Create a project status report with sections for milestones, risks, and next steps

# Read and summarize an existing document
> /docx Summarize the key terms in contracts/vendor-agreement.docx

# Edit an existing document
> /docx Update the dates in proposal.docx to reflect the new Q4 timeline

# Convert formats
> /docx Convert this markdown spec into a formatted Word document with a table of contents
```

The skill handles formatting, tables, headers, lists, and page layout. It works with templates (`.dotx`) too, so you can populate a company template programmatically.
