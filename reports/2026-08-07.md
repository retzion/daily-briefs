## Featured: Cross-Session Messaging (`SendMessage` + `ListAgents`)

New in v2.1.224, Claude Code sessions can now discover and message each other on the same machine (macOS/Linux). `ListAgents` shows all running sessions — subagents you spawned, other local CLI sessions, and cloud sessions. `SendMessage` lets you send a message to any of them by name.

**Why it matters:** This enables multi-session coordination workflows. A long-running background agent can notify a foreground session when it finds something. A review session can ask an implementation session to pause. Multiple scheduled routines can share findings without going through files.

**Quick example:**
```
# In session A — list who's around
ListAgents()
# Returns: ["build-watcher", "test-runner-bg"]

# Send a message to the build watcher
SendMessage({ to: "build-watcher", message: "Build passed — go ahead with deploy" })
```

Previously, cross-session communication required writing to shared files or external tools. Now it's built in.
