## Featured: Shell Head Start (Early Bash Startup)

New in v2.1.327, Shell Head Start is a performance optimization that reduces latency for the first Bash command in a Claude Code session.

**What it does:** Instead of waiting for full session initialization to complete before executing your first shell command, Claude Code now begins the Bash subprocess early. This shaves noticeable time off the first tool call, especially on slower machines or in cloud sessions with heavier startup.

**Why it matters:** In interactive sessions, the first Bash command often sets the tone — `git status`, `npm test`, or a build check. Faster time-to-first-command makes the session feel more responsive, particularly for users running Claude Code in containers or CI environments.

**Usage:** It's on by default — no configuration needed. If you encounter issues with early shell execution (e.g., shell profile scripts that depend on session state), disable it:

```bash
export CLAUDE_CODE_DISABLE_SHELL_HEAD_START=1
```

A small but meaningful quality-of-life improvement for daily Claude Code users.
