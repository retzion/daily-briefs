## Featured: MCP Stateless Core (2026-07-28 Spec)

The MCP 2026-07-28 specification is the biggest protocol update since launch. The headline change: MCP moves from a **bidirectional stateful** model to a **stateless request/response** core — servers no longer need persistent connections.

**Why it matters**: Stateless MCP servers can run as serverless functions (Lambda, Cloud Functions, edge workers) instead of requiring long-lived processes. This dramatically lowers the barrier to deploying and scaling MCP servers.

**What's new**:
- Stateless request/response as the default transport
- Extensions framework: MCP Apps and Tasks ship as versioned add-ons
- Hardened OAuth/OIDC authorization
- 12-month deprecation policy for breaking changes
- Beta SDKs: Python 2.0.0b1, TypeScript v2, Go v1.7.0-pre.1, C# 2.0.0-preview.1

**For Claude Code users**: Existing MCP servers keep working — the stateful transport is still supported. But new servers you build can be simpler. A minimal stateless MCP server is just a request handler you deploy as an edge function.
