## Featured: `engines["claude-code"]` in plugin.json

**What it is:** New in v2.1.323, the `engines` field in `plugin.json` lets plugin authors declare which Claude Code versions their plugin supports — similar to how Node.js packages use `engines` in `package.json`.

**Why it matters:** As Claude Code's plugin ecosystem grows, breaking changes between versions can silently break plugins. This field gives both authors and users a clear compatibility contract. Claude Code can warn users before installing an incompatible plugin, and plugin authors can target specific version ranges.

**Usage example:**
```json
{
  "name": "my-awesome-plugin",
  "version": "1.0.0",
  "engines": {
    "claude-code": ">=2.1.320 <3.0.0"
  }
}
```

This tells Claude Code the plugin requires v2.1.320 or later but below v3.0.0. Standard semver range syntax applies.
