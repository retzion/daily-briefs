## Featured: PreModelSwitch / PostModelSwitch Hooks

Claude Code v2.1.251 introduced two new hook lifecycle events that give teams fine-grained control over model switching during sessions.

**What they are:** `PreModelSwitch` fires before a model change takes effect; `PostModelSwitch` fires after. Both receive `from_model` and `to_model` fields (unlike `SessionStart` which only gets `model`).

**Why it matters:** Enterprise teams doing controlled model rollouts can use `PreModelSwitch` to gate which models are allowed — a hook that exits with code 2 blocks the switch entirely, even in `bypassPermissions` mode. `PostModelSwitch` can log model transitions, update dashboards, or annotate sessions with the active model.

**Quick example** (`.claude/settings.json`):
```json
{
  "hooks": {
    "PreModelSwitch": [{
      "matcher": { "to_model": "claude-opus-5" },
      "hooks": [{
        "type": "command",
        "command": "echo 'Opus 5 not approved yet' >&2; exit 2"
      }]
    }]
  }
}
```
This blocks any switch to `claude-opus-5`, letting teams enforce model policies without disabling the model picker entirely.
