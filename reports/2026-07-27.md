## Featured: Plan Mode (`/plan` + Shift+Tab)

Plan Mode is Claude Code's deliberate counterpart to Auto Mode. It puts the agent in a **read-only state** where it explores your codebase, maps dependencies, and produces a step-by-step implementation plan — without touching any files.

**Why it matters:** The highest-leverage pattern in agentic coding is spending 80% of your time planning and 20% supervising execution. Plan Mode enforces this discipline structurally. It's especially valuable for large refactors, unfamiliar codebases, or any task where "just start coding" leads to costly dead ends.

**How to use it:**
```
# Activate via slash command
> /plan

# Or cycle permission modes mid-session with Shift+Tab:
#   default → acceptEdits → plan → default

# Or start a session in plan mode
claude --permission-mode plan
```

**Workflow tip:** Start every complex task in Plan Mode. Review and refine the plan. Then press Shift+Tab to switch to default or acceptEdits mode and let Claude execute. If it drifts, Shift+Tab back to plan mode to re-orient.
