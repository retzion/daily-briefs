## Featured: Detachable Desktop Panes

Claude Code Desktop now lets you **pop any pane out into its own window** and dock it back later. This is especially useful for multi-monitor setups where you want to keep the diff view or terminal on a second screen while Claude works in the main window.

**Available panes:** chat, diff, browser, terminal, files, plans, tasks, and subagents.

**How to use:**
1. In Claude Code Desktop, hover over any pane's title bar
2. Click the pop-out icon (or drag the pane out of the main window)
3. Position it on any monitor
4. To dock it back, close the floating window or drag it back into the main layout

This turns Claude Code Desktop into a true multi-window IDE experience — you can watch the diff evolve on one screen while chatting with Claude on another, or keep the subagent view visible while working on tasks.
