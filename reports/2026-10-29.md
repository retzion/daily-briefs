## Featured: Granola Transcript Saver (`anthropic-skills:granola-transcript-saver`)

An official Anthropic skill that bridges meeting transcripts from [Granola](https://granola.ai) into your Claude Code sessions. Granola is a popular AI meeting notes tool that records and summarizes meetings; this skill lets you save and reference those transcripts directly from Claude Code.

**Why it's useful:** Developers often leave meetings with action items, architectural decisions, and context that needs to translate into code. Instead of manually copy-pasting notes, this skill pulls meeting context directly into your coding session — making it easy to implement what was discussed while the context is fresh.

**Usage:**
```
# Invoke the skill in Claude Code
/granola-transcript-saver

# Claude will connect to Granola, pull recent transcripts,
# and save them in a format you can reference during coding
```

The broader Granola ecosystem also includes community plugins for exporting to Obsidian-style markdown and an official MCP server with OAuth-based authentication. The built-in skill offers the simplest path for Claude Code users.
