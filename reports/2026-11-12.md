## Featured: `run_secret_scanning` (GitHub MCP Tool)

Given this week's Apiiro report on thousands of leaked credentials in public repos, the `run_secret_scanning` tool available via Claude Code's GitHub MCP server deserves a spotlight.

**What it is:** A tool exposed through the GitHub MCP server (`mcp__github__run_secret_scanning`) that triggers GitHub's secret scanning on a repository directly from your Claude Code session. It checks for accidentally committed API keys, tokens, passwords, and other credentials.

**Why it matters:** The Apiiro research found that Claude Code's `.claude/settings.local.json` file was the #1 source of leaked secrets — saved there by the "Don't Ask Again" approval flow. Running a secret scan before pushing is a simple defense.

**Quick usage:** In a Claude Code session with the GitHub MCP server connected:
```
> Scan this repo for leaked secrets before I push

Claude will call run_secret_scanning on your repo and report any findings
```

**Pro tip:** Add `.claude/settings.local.json` to your `.gitignore` immediately if it isn't already there. Combine with the `security-review` skill (`/security-review`) for a defense-in-depth approach.
