## Featured: Google Drive MCP Connector

The Google Drive MCP connector lets Claude Code read, search, create, and update files in your Google Drive directly from a coding session — no context-switching to a browser.

**What it is:** A first-party Anthropic-hosted MCP server providing tools like `search_files`, `read_file_content`, `create_file`, `list_recent_files`, and `get_file_metadata`. It handles Google Docs, Sheets, Slides, PDFs, Word docs, images, and more.

**Why it's useful:** Developers and teams often keep specs, meeting notes, design docs, and reports in Google Drive. With this connector, Claude Code can pull context from those documents mid-session, write summaries or generated content back to Drive, and automate doc-based workflows (like this daily brief's Google Doc update).

**Quick setup:**
1. On claude.ai/code → Settings → Connectors → enable Google Drive
2. Authenticate with your Google account
3. The tools load automatically in new Claude Code sessions

**Example usage in a session:**
```
"Read the PRD in my Google Drive titled 'Auth Revamp Q3'
 and create an implementation plan based on it."
```

Claude Code will call `search_files` to find the doc, `read_file_content` to pull its text, and then work with the content as if it were a local file.
