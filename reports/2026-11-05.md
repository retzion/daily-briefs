## Featured: `artifact-diagramming` Skill

The `artifact-diagramming` skill is a built-in Claude Code skill that provides guidance for creating diagrams inside published Artifacts. It covers when a diagram earns its place, how to draw inline SVGs that stay legible in both light and dark themes, and the rendering mechanics that make diagrams work reliably.

**Why it's useful:** Architecture diagrams, flowcharts, and system overviews are common in technical communication, but getting them to render correctly in both themes with proper sizing is tricky. This skill teaches the design principles so diagrams look professional without external tools.

**Usage:**
```
# Load the skill before creating a diagram artifact
/artifact-diagramming

# Or invoke it naturally — Claude Code loads it when you ask for a diagram
"Create an architecture diagram showing our microservices"
```

The skill covers: choosing between diagrams and text, inline SVG mechanics (viewBox, stroke/fill tokens on `:root`), dark-mode color adaptation, and layout patterns that work at phone width.
