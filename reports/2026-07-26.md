## Featured: ToolSearch (Deferred Tool Loading)

When Claude Code connects to multiple MCP servers, the raw tool schemas can consume 50k+ tokens of context before you even start working. **ToolSearch** solves this by registering tools by name only — their full JSON schemas aren't loaded until the moment they're actually needed.

**Why it matters:** A five-server MCP setup that previously cost 50k+ tokens of upfront context now costs almost nothing until tools are invoked. Anthropic reports an ~85% reduction in context overhead.

**How it works:**
```
# Tools appear as deferred in system reminders:
# "mcp__github__create_pull_request — schema NOT loaded"

# When needed, Claude calls:
ToolSearch("select:mcp__github__create_pull_request")

# The full schema loads on demand, and the tool becomes callable
```

**Practical impact:** You can have dozens of MCP servers configured (GitHub, Postgres, Linear, Sentry, Google Drive, Slack) without drowning your context window. Tools load just-in-time, keeping your effective context free for actual work.
