## Featured: `/google-workspace` Skill (Google Docs, Sheets & Slides from Claude Code)

**What it is:** The `anthropic-skills:google-workspace` skill lets Claude Code read, create, and edit Google Docs, Sheets, and Slides directly from a coding session — no browser tab-switching required. It went public beta on October 7 alongside the broader Google Workspace connector rollout.

**Why it matters:** Developers frequently juggle code alongside documentation, specs, and project tracking spreadsheets. This skill bridges the gap: update a design doc after refactoring, populate a spreadsheet with test results, or build a slide deck summarizing a PR — all without leaving the terminal.

**Usage example:**
```
> Update the project spec in Google Docs to reflect the new API endpoints we just added

Claude Code reads the doc via the Google Drive connector, edits the
relevant sections, and writes back — citing which sections changed.
```

You can also combine it with other skills:
```
> /google-workspace

Then: "Create a new Google Sheet with our test coverage data from the last 5 runs"
```

The skill works with the Google Drive MCP connector tools (`read_file_content`, `create_file`, `update_file`) and requires the Google Drive connection to be configured in your Claude Code session.
