## Featured: Claude Desktop Release Channels (Stable vs Latest)

Anthropic introduced release channels for Claude Desktop on November 17. This gives users control over how quickly they receive updates.

**What it is:** Two update tracks — **Stable** (default) gets less frequent, more tested releases. **Latest** gets a new build roughly every day, so fixes and features arrive sooner but with slightly more risk.

**Why it matters:** Teams running Claude Desktop in production workflows can now stay on Stable for reliability, while power users and early adopters can opt into Latest to get new features immediately. IT-managed devices are locked to Stable automatically.

**Key details:**
- Available on Mac and Windows (not Linux or Microsoft Store installs)
- Switching from Latest back to Stable does not downgrade — you keep your current version until a newer Stable build passes it
- Managed devices with IT policies don't see the option; they always get Stable

**How to switch:** Open Claude Desktop → Settings → About → Release Channel → select Stable or Latest.

This is especially relevant after a recent regression in Latest build 5.42931.0 was quickly corrected — illustrating exactly why the two-track system exists.
