## Featured: `/claude-api upgrade` (Automated SDK Migration)

Added in v2.1.239 (Aug 21), `/claude-api upgrade` is a codemod that automatically rewrites your Python project from `anthropic` SDK 0.x to 1.x. Unlike the `/claude-api` reference skill (a quick API lookup), this subcommand scans your codebase, identifies deprecated patterns, and rewrites them in place.

**What it handles:**
- Migrates `httpx.Timeout` → `anthropic.Timeout`
- Removes deprecated Text Completions API calls
- Updates removed parameters (`temperature`, `top_p`, `top_k` on Messages methods)
- Adjusts HTTP layer from `httpx` to `httpx2`
- Enforces Python 3.10+ (SDK 1.x requirement)

**Usage:**
```
/claude-api upgrade
```

Run it in any directory with a Python project that imports `anthropic`. Claude scans the codebase, identifies 0.x patterns, and applies the migration — no manual find-and-replace needed.
