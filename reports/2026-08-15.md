## Featured: `@` Mentions (Cross-Session Prompt Mentions)

Claude Code sessions can now communicate with each other using `@` mentions directly in the prompt. This builds on the SendMessage/ListAgents infrastructure but removes the friction — instead of calling ListAgents to discover session names and then invoking SendMessage, you just type `@` followed by the session name.

**Why it's useful:** If you have a background agent watching a PR and another session doing development, you can message between them without switching windows or remembering tool syntax. It's especially powerful with the recent cross-session messaging and Remote Control features — your desktop session can ping a cloud routine, or vice versa.

**Quick usage:**
```
> @my-pr-watcher what's the CI status on PR #42?
```
The message routes to the session named "my-pr-watcher" if exactly one live session matches. If multiple sessions share a name, you'll be prompted to disambiguate.

**Tip:** Name your sessions descriptively (`claude --name pr-watcher`) so `@` mentions are intuitive across your workflow.
