## Featured: Account Email Privacy Guard (v2.1.317)

Claude Code v2.1.317 introduced a security safeguard that prompts for confirmation before any web or shell tool call sends your account email address over the network. Previously, certain tool calls (like `WebFetch` or `Bash` commands involving HTTP requests) could inadvertently transmit your registered email in headers or payloads. Now Claude Code intercepts these and asks before proceeding.

**Why it matters:** Email addresses are low-grade PII that can be used for tracking, phishing targeting, or account enumeration. This guard applies the principle of least surprise — your identity shouldn't leak without your knowledge during routine coding sessions.

**In practice:** You'll see a confirmation prompt like:

```
This tool call would send your account email (you@example.com) over the network.
Allow? [y/N]
```

You can approve once or adjust your permission settings to allow it globally if your workflow requires it. The guard works across all tool types — web searches, shell commands, and MCP server calls.
