## Featured: Focus View (VS Code, `Ctrl+Alt+F`)

Introduced in Claude Code v2.1.221, Focus View is a VS Code chat-menu toggle that declutters the conversation by collapsing all tool activity (file reads, edits, grep results, bash output) into compact, expandable per-turn summaries. A live indicator shows which tool is currently running.

**Why it's useful:** Claude Code sessions generate verbose tool output that buries the actual conversation. Focus View lets you follow the agent's reasoning without scrolling past hundreds of lines of grep results and file diffs — while still letting you expand any turn to inspect tool details when needed.

**How to use it:**
- Toggle with `Ctrl+Alt+F` (or `Cmd+Alt+F` on macOS)
- Or run the VS Code command: `Claude Code: Toggle Focus view`
- Tool activity collapses into one-line summaries per turn
- Click any summary to expand and see full tool output
- A spinner indicator shows the currently executing tool in real time
