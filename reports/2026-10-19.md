## Featured: Built-In Browser Skill (`anthropic-skills:built-in-browser`)

Claude Code cloud sessions come with Chromium pre-installed at `/opt/pw-browsers/chromium`, configured for Playwright (`PLAYWRIGHT_BROWSERS_PATH` and `PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD` are set automatically). The **built-in browser skill** (`anthropic-skills:built-in-browser`) wraps this into a high-level capability Claude can invoke during a session — navigating pages, taking screenshots, extracting content, and interacting with web UIs.

**Why it's useful:** When working in a cloud session, you often need to verify a deployed change looks right, check a staging URL, scrape reference documentation, or confirm an API endpoint returns the expected HTML. Instead of writing a one-off Playwright script, the built-in browser skill handles it.

**Quick usage:**
```
# In a Claude Code session, just ask naturally:
> Open https://staging.example.com/dashboard and take a screenshot
> Check if the login page at https://app.example.com loads without errors
> Navigate to our docs site and find the API rate limit section
```

The skill works out of the box in cloud sessions — no `playwright install` needed (it's explicitly skipped). For local sessions, ensure Chromium is accessible or point `executablePath` to your browser binary.

**Tip:** Combine with the `/run` skill to launch a dev server, then use the built-in browser to visually verify changes end-to-end — all without leaving your terminal.
