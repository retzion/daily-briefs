## Featured: `CLAUDE_CODE_SUBAGENT_EFFORT` Environment Variable

New in Claude Code v2.1.316, this environment variable gives you fine-grained control over the reasoning effort of subagents spawned during your session.

**Why it matters:** When running workflows or multi-agent reviews, subagents can burn through tokens at high effort levels. This variable lets you dial them down without affecting your main session's reasoning depth.

**Precedence order:**
1. `CLAUDE_CODE_EFFORT_LEVEL` (session-wide)
2. Per-call `effort` parameter on the Agent tool
3. Agent definition file's own effort setting
4. `CLAUDE_CODE_SUBAGENT_EFFORT` (fallback default)

**Quick usage:**
```bash
# Run session at high effort, but keep subagents lean
CLAUDE_CODE_SUBAGENT_EFFORT=low claude

# Or set in your shell profile / settings.json env block
export CLAUDE_CODE_SUBAGENT_EFFORT=medium
```

Pairs well with `CLAUDE_CODE_SUBAGENT_MODEL` for full control over subagent cost and behavior.
