## Featured: VS Code Multi-Chat Sessions
VS Code 1.128 (July 8) introduced **multi-chat support** for Claude agent sessions — a feature that lets you run multiple related conversations inside a single session instead of opening separate windows.

**Why it's useful**: You can compare approaches side by side, fork from an earlier turn to explore an alternative, or run parallel workstreams without losing shared context. Each chat can use a different model (Sonnet 5, Opus 4.8, Haiku 4.5), so you can match model power to task complexity within one session.

**Quick usage**:
1. Open a Claude agent session in VS Code
2. Click the "+" to add a peer chat, or right-click any turn and select "Fork Chat"
3. Send prompts to multiple chats simultaneously — they run concurrently
4. Switch between chats to compare results or continue different threads

This is the VS Code equivalent of `/branch` in the CLI, but with a visual interface that makes juggling parallel explorations much more intuitive.
