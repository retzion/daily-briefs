## Featured: `/auto-mode-setup`
New in v2.1.304, `/auto-mode-setup` is a guided wizard that teaches Claude Code's auto mode about your specific development environment. Auto mode lets Claude decide which tools to run without per-call permission prompts, but it works best when it understands your project's tooling, test commands, and build system.

**Why it matters:** Auto mode's safety classifier needs to know what's safe in your context. A `make deploy` in a staging environment is routine; the same command targeting production is dangerous. `/auto-mode-setup` walks you through declaring these boundaries once instead of repeatedly approving or denying prompts.

**Usage:**
```
/auto-mode-setup
```
The wizard asks about your:
- Build and test commands
- Deployment targets and safety boundaries
- Preferred permission defaults for common tools

It works on all supported providers including Bedrock, Vertex, and Foundry (previously limited to Anthropic direct). The configuration persists in your project's `.claude/settings.json`.
