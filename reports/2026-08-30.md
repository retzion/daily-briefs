## Featured: SendFeedback Tool
Claude Code v2.1.247 (Aug 26) introduced the **SendFeedback** tool — Claude now auto-drafts bug reports when something goes wrong in your session.

**When it triggers:**
- A tool or command keeps failing
- Claude can't help with something you asked
- You point out a mistake, or Claude notices one itself
- You explicitly ask Claude to file feedback

**How it works:**
Claude drafts a structured feedback report and queues it locally. Nothing is sent to Anthropic until you review and approve it via `/feedback`. The report includes the error context, what Claude tried, and reproduction details.

**Why it's useful:**
Instead of manually describing bugs, Claude captures the full context of what went wrong while it's fresh. You get a well-structured report you can review, edit, and submit in one step — or discard if it's not worth filing.

**Quick usage:**
```
> "Claude, that last edit broke my tests — file a bug about it"
# Claude drafts a report → review it with /feedback → approve to send
```
