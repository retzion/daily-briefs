## Featured: `/doctor prompt-audit`

New in v2.1.283, `/doctor prompt-audit` scans your project's CLAUDE.md files, custom skills, agent definitions, and slash commands for outdated prompting patterns — deprecated tool references, stale model names, removed settings, or anti-patterns that waste tokens with current models.

**Why it's useful:** As Claude Code evolves rapidly (4 releases this week alone), project instructions accumulate cruft. A CLAUDE.md written for Sonnet 4 may use workarounds that are unnecessary or counterproductive on Opus 5.5. This command surfaces those issues automatically.

**Usage:**
```
/doctor prompt-audit
```

It reports findings grouped by file with severity levels (warning, info) and suggests specific fixes. Pair it with `/doctor` (general setup diagnostics) and `/skill-doctor` (skill cost audit) for a complete project health check.
