## Featured: Self-Hosted Runners (`claude self-hosted-runner`)

New in v2.1.224 (public beta), self-hosted runners let Team and Enterprise orgs run full Claude Code web, mobile, and desktop sessions on their own infrastructure instead of Anthropic's cloud.

**Why it matters:** Some organizations can't send code or context to external servers. Self-hosted runners keep all session data — file reads, tool execution, git operations — on machines you control, while still using Claude's API for model inference. Two modes are available:

- **Fixed runners** — long-lived processes on dedicated machines that pick up sessions from a queue
- **On-demand runners** — spun up per-session in containers, ideal for auto-scaling

**Quick setup:**
```bash
# Register a runner with your org
claude self-hosted-runner register --org <org-id> --name "build-server-1"

# Start accepting sessions
claude self-hosted-runner start

# Team members connect from the web/desktop/mobile as usual —
# sessions are routed to your runner instead of Anthropic's cloud
```

Runners support the full Claude Code feature set: subagents, worktrees, MCP servers, hooks, and plugins. Sessions appear in `claude agents` alongside cloud sessions.

**Blog post:** [Run Claude Code sessions on your own compute](https://claude.com/blog/run-claude-code-sessions-on-your-own-compute)
