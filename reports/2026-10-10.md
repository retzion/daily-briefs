## Featured: Program Status Protocol (OSC 7501)

Claude Code v2.1.295 added support for the **Program Status Protocol** via OSC 7501 terminal escape sequences. This lets your terminal emulator display whether Claude Code is actively working, waiting for input, or finished.

**Why it's useful:** When running Claude Code in one tab while working in others, your terminal can show at a glance whether Claude needs attention — through tab indicators, title bar changes, or notification badges, depending on your terminal emulator.

**How it works:** Claude Code automatically emits OSC 7501 sequences — no configuration needed. Your terminal emulator must support the protocol. Terminals like Ghostty, WezTerm, and others with modern escape sequence support are most likely to pick it up.

```
# States reported via OSC 7501:
# - Working: Claude is actively processing
# - Waiting: Claude needs user input
# - Done: Task complete
```

This is especially valuable for long-running agentic sessions where you've kicked off a task and switched context. Instead of polling the Claude Code tab, just glance at the tab title or status indicator.
