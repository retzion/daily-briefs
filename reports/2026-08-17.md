## Featured: `forward_user_identity` Gateway Setting

New in v2.1.233 (August 14), the `forward_user_identity` setting lets organizations using the Claude Code apps gateway attribute API spend to individual users rather than just the organization-level gateway token.

**Why it matters:** Teams sharing a single gateway token see total spend but can't tell who's using what. This setting forwards the authenticated user's identity with each API call, enabling per-user spend dashboards, rate limits, and audit trails.

**Usage:** Enable it in your apps gateway configuration:

```json
{
  "forward_user_identity": true
}
```

Once enabled, each API request includes the user's identity (typically their SSO email), which appears in usage dashboards broken down by user. Best for Enterprise and Team admins managing multi-developer Claude Code deployments who need cost visibility or per-user spend caps.
