## Featured: `claude-code-guide` Agent Type

The `claude-code-guide` is a specialized agent type you can spawn from Claude Code to answer questions about Claude Code itself, the Claude Agent SDK, the Claude API (Messages API, tool use, prompt caching), and Claude Tag (Slack integration).

**Why it's useful:** Instead of searching docs yourself, you can delegate questions to a focused agent that has access to web search and file reading but no write tools — so it researches safely and returns concise answers. It's ideal for "Can Claude Code do X?" or "How do I set up MCP servers?" questions mid-session.

**Usage example:**
```
Agent({
  subagent_type: "claude-code-guide",
  description: "MCP auth question",
  prompt: "How do I authenticate an MCP server that requires OAuth? Walk me through the setup."
})
```

Or from the CLI, any time you're unsure about a feature, spawn the guide agent to look it up without breaking your current flow. It checks live docs and the web, so answers stay current even as Claude Code ships weekly.
