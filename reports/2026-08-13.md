## Featured: VS Code Session Groups

Claude Code v2.1.229 adds **session groups** to the VS Code sidebar — a simple way to organize your coding sessions by project, feature, or task.

**Why it's useful:** Power users of Claude Code in VS Code accumulate dozens of sessions. Without organization, the sidebar becomes a wall of timestamped entries. Session groups let you cluster related sessions together — one group per feature branch, one per project, one for experiments.

**How to use it:**
- Right-click in the Claude Code sidebar → **Create Group**
- Name it (e.g., "auth-refactor", "bug-fixes", "spike")
- Drag sessions into groups, or right-click to rename/delete groups

Also new in the same release: The `/btw` side-question panel (for asking quick questions without interrupting your main agent flow) is now resizable.
