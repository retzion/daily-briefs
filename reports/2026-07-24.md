## Featured: `/pptx` Skill (Presentation Operations)

The built-in `/pptx` skill gives Claude Code the knowledge to create, read, edit, and transform PowerPoint files without trial-and-error library debugging.

**What it does:** Covers the full .pptx/.potx lifecycle — creating slide decks from scratch or data, reading/extracting content from existing presentations, editing slides (text, images, layouts, speaker notes), working with templates, and combining or splitting deck files. It selects the right approach using `python-pptx` and handles the quirks (EMU units, placeholder indexing, master slide inheritance) so your first attempt works.

**Why it's useful:** PowerPoint's internal object model is notoriously fiddly — placeholder indices vary by layout, positioning uses English Metric Units, and template inheritance is non-obvious. Without the skill, Claude Code often guesses on these details. The skill encodes the correct patterns so deck generation comes out right.

**Quick usage:**
```
# Create a deck from a markdown outline
/pptx
"Create a 10-slide pitch deck from outline.md using our template.potx"

# Extract all speaker notes to a document
/pptx
"Extract speaker notes from quarterly-review.pptx into notes.md"

# Update branding across a deck
/pptx
"Replace all instances of the old logo with new-logo.png in deck.pptx"
```

Pairs well with `/pdf` and `/xlsx` for end-to-end document workflows — e.g., pull data from a spreadsheet, generate charts, and assemble them into a branded deck.
