## Featured: `agent.spawn` (Plugin Subagent Spawning API)

New in v2.1.289, `agent.spawn` lets Claude Code plugins programmatically create subagents — a significant extension of the plugin system that was previously limited to hooks and UI modifications.

**What it is:** A plugin API that allows mod/plugin code to spawn subagents with their own conversation context, tool access, and optional worktree isolation. This means plugins can orchestrate multi-agent workflows without relying on Claude's built-in Agent tool decisions.

**Why it matters:** Before `agent.spawn`, plugins could react to events (hooks) and modify UI, but couldn't initiate autonomous work. Now a plugin can, for example, spin up a background agent to run tests after every edit, or coordinate specialist agents for different parts of a codebase.

**Quick example:**
```typescript
// In a plugin hook, spawn a subagent for a specific task
const result = await agent.spawn({
  prompt: "Review the latest changes for security issues",
  model: "sonnet",
  label: "security-scan"
});
```

Combined with the new agent state support in the same release, plugins can now track and manage the lifecycle of agents they spawn.
