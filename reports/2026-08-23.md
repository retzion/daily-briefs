## Featured: Artifact Asset Uploads (`upload_asset`)

Claude Code Artifacts can now embed local media files — images, videos, PDFs, and fonts — directly into published pages via the **asset upload** system, making artifacts truly self-contained rich documents without base64-bloating your HTML.

**Why it's useful:** Previously, embedding an image in an artifact meant inlining it as a data: URI, which counted against the 16MB page limit and made the HTML unwieldy. Asset uploads store files separately in the artifact's asset store, referenced by a clean relative URL (`_blob/{id}`), keeping the page lean while supporting rich media.

**How it works:**

```
# Upload a file to an existing artifact
Artifact(action: "upload_asset", url: "<artifact-url>", file_path: "chart.png")
# Returns: { url: "_blob/abc123..." }

# Reference it in your HTML
<img src="_blob/abc123..." alt="Chart" />

# List all assets on an artifact
Artifact(action: "list_assets", url: "<artifact-url>")

# Download an asset locally
Artifact(action: "read_asset", url: "<artifact-url>", asset_id: "abc123...")

# Remove an asset no longer referenced
Artifact(action: "delete_asset", url: "<artifact-url>", asset_id: "abc123...")
```

The artifact must declare the `assets` capability. Supports images, videos, PDFs, and font files. Great for dashboards with charts, reports with screenshots, or design specs with embedded mockups.
