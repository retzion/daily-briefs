## Featured: `/output-style` Command
Upgraded in v2.1.269, `/output-style` lets you switch Claude Code's response style on the fly — now working over Remote Control and in cloud/headless sessions.

**What it does:** Lists available output styles and switches between them mid-session. No restart needed.

**Built-in styles:**
- `Default` — standard Claude Code output
- `Concise` — terse, minimal prose
- `Explanatory` — more context and reasoning
- `Proactive` — suggests next steps and improvements
- `Learning` — teaches as it works

**Why it's useful:** Different tasks call for different verbosity. Debugging a gnarly issue? Switch to `Explanatory`. Rapid-fire file edits? `Concise` keeps output tight. Teaching a teammate? `Learning` mode. The cloud/headless support in v2.1.269 means your automated routines and Remote Control sessions can set a style too.

**Quick usage:**
```bash
# List all available styles
/output-style

# Switch to concise mode
/output-style Concise

# Set via config for persistence
claude config set outputStyle "Concise"

# Custom style from a markdown file
claude config set outputStyle ./my-style.md
```
