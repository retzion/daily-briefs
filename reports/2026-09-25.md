## Featured: MCP Elicitation (Browser Auth Flows)

Claude Code v2.1.281 adds **URL-mode elicitation** for MCP servers using the 2026-07-28 protocol. This lets an MCP server ask Claude Code to open a browser-based authentication flow — so servers that require OAuth, SSO, or other browser-mediated consent can trigger that flow directly from your coding session instead of requiring manual token setup.

**Why it matters:** Many MCP servers connect to services that need OAuth tokens (GitHub, Jira, cloud consoles). Previously you had to obtain tokens out-of-band and configure them manually. With elicitation, the server says "I need the user to authenticate" and Claude Code opens the browser, completes the flow, and passes the result back — seamless.

**How it works:**
```
# When connecting to an MCP server that supports elicitation:
# 1. Server requests authentication via the elicitation protocol
# 2. Claude Code opens your default browser to the auth URL
# 3. You approve in the browser
# 4. The token flows back to the MCP server automatically

# Requires: MCP server running the 2026-07-28 protocol
# Claude Code v2.1.281+
```

This pairs well with `claude mcp login`/`claude mcp logout` (featured Jun 25) for CLI-based auth, giving you two paths depending on whether the server or the user initiates the flow.
