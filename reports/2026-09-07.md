## Featured: `--append-subagent-system-prompt-file` (Subagent Prompt Files)

When building custom agent architectures in Claude Code, subagent system prompts can grow to multi-page instructions — too long for a command-line argument. The `--append-subagent-system-prompt-file` flag (added in v2.1.261) lets you load the prompt from a file instead.

**Why it matters:** Custom agent types (`.claude/agents/*.md`) and orchestrated workflows often need detailed, domain-specific instructions for subagents — coding standards, review checklists, security policies. Passing these inline hits shell argument limits and is hard to version-control. A file-based approach keeps prompts maintainable and in your repo.

**Usage:**
```bash
# Load a detailed reviewer prompt from a file
claude --append-subagent-system-prompt-file ./prompts/security-reviewer.md

# Combine with other flags
claude --append-subagent-system-prompt-file ./prompts/reviewer.md \
       --allowedTools "Read,Grep,Glob"
```

The file contents are appended to the subagent's system prompt, so you can layer project-specific context on top of the default behavior. Requires Claude Code v2.1.261+.
