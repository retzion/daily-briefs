## Featured: `timeFormat` / `timeZone` Settings
New settings added in Claude Code v2.1.257 that let you customize how timestamps appear in your session — the turn-end clock and transcript-view timestamps.

**What it does:** Two settings control time display:
- `timeFormat` — choose `"12h"`, `"24h"`, `"24h-utc"`, or any `strftime` pattern (e.g., `"%H:%M:%S %Z"`)
- `timeZone` — set your IANA timezone (e.g., `"America/New_York"`, `"Europe/London"`)

**Why it's useful:** If you work across timezones or review transcripts from cloud sessions that defaulted to UTC, these settings ensure timestamps make sense at a glance. The `strftime` escape hatch covers any edge case (seconds, timezone abbreviation, date+time).

**Quick usage:**
```bash
# Set 24-hour time in your timezone
claude config set timeFormat "24h"
claude config set timeZone "America/Chicago"

# Custom strftime pattern with seconds
claude config set timeFormat "%H:%M:%S %Z"
```

These are user-level settings that persist across sessions.
