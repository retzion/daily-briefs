## Featured: Code Review Organization Levels

New in Claude Code v2.1.304, organization owners can now configure a default Code Review depth across their entire org and override it per repository. Three levels are available:

- **Quick** — fast, high-confidence checks only; best for low-risk changes
- **Standard** — balanced review (the default); catches most issues without excessive latency
- **Deep** — thorough multi-pass review; suited for security-critical or complex codebases

Admins configure this in their org settings. Per-repo overrides let teams match review intensity to codebase criticality. Individual developers invoke reviews as usual with `/code-review` — the org/repo level applies automatically.

To override locally for a single review:
```
/code-review --level deep
```

This is useful for enterprise teams that want consistent review standards without relying on individual developers to remember flags.
