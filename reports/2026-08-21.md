## Featured: `ANTHROPIC_DEFAULT_MODEL` Environment Variable
New in v2.1.236 (Aug 19), this env var lets you set which model new Claude Code sessions start on — without locking you in. Unlike the existing `ANTHROPIC_MODEL` which hard-pins every session, `ANTHROPIC_DEFAULT_MODEL` acts as a soft default: if you pick a different model with `/model` during a session, your choice persists for that session.

**Why it's useful:** Teams can standardize on a model (e.g., `claude-sonnet-5` for cost-conscious work) while letting individual developers override when they need more horsepower. Useful in CI/CD pipelines and shared dotfiles where you want a sensible default, not a mandate.

**Usage:**
```bash
# In your shell profile or .env
export ANTHROPIC_DEFAULT_MODEL="claude-sonnet-5"

# Sessions start on Sonnet 5, but /model still works
claude  # → starts on claude-sonnet-5
# type /model → pick claude-opus-5 → stays on Opus for this session
```
