## Featured: Cloud Session Plugin Sync (`@synced`)
New in v2.1.239 (Aug 21), Claude Code now syncs plugins between your claude.ai account and cloud sessions. Plugins installed via the web marketplace appear as `name@synced` in your session, distinguishing them from locally installed versions.

**Why it matters:** Teams using both local and cloud Claude Code sessions previously had to manage plugins separately in each environment. Now your plugin configuration follows you — install once on claude.ai, use everywhere. The `@synced` suffix prevents cloud-synced plugins from silently overriding locally installed versions with different configurations.

**Usage:**
```bash
# List all plugins including synced ones
claude plugin list
# Output shows: my-plugin@synced, local-plugin, team-tool@synced

# Enable/disable synced plugins
claude plugin enable security-scanner@synced
claude plugin disable security-scanner@synced

# Local installs always take precedence
claude plugin install ./my-local-version  # overrides my-plugin@synced
```
