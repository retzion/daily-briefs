## Featured: Workflow `budget` Global (Token-Aware Agent Orchestration)

When running Dynamic Workflows in Claude Code, the `budget` global lets your script self-pace based on the user's token directive (e.g., "+500k"). This prevents runaway multi-agent runs and lets you scale depth dynamically.

**What it provides:**
- `budget.total` — the token target (null if none set)
- `budget.spent()` — output tokens used this turn across all workflows
- `budget.remaining()` — tokens left before the ceiling

**Quick usage — loop until budget exhausted:**
```javascript
const bugs = []
while (budget.total && budget.remaining() > 50_000) {
  const result = await agent("Find bugs in this codebase.", {schema: BUGS_SCHEMA})
  bugs.push(...result.bugs)
  log(`${bugs.length} found, ${Math.round(budget.remaining()/1000)}k remaining`)
}
```

**Why it matters:** Without `budget`, a workflow either runs a fixed number of agents (possibly too few or too many) or risks hitting the 1000-agent cap. With `budget`, you write open-ended discovery loops that naturally stop when the user's spend directive is met. The user controls cost from the prompt (`+200k` for a quick scan, `+2M` for a deep audit) and the script adapts automatically.

**Pro tip:** Always guard on `budget.total` — without a directive, `remaining()` returns `Infinity` and your loop runs to the agent cap.
