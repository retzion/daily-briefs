## Featured: AGENTS.md Support

Claude Code v2.1.277 (Sept 18) introduced native support for `AGENTS.md` — a cross-tool project instruction file that works with Claude Code, GitHub Copilot, OpenAI Codex, and Gemini CLI without any tool-specific configuration.

**Why it matters:** Until now, each coding agent had its own config file (`CLAUDE.md`, `.github/copilot-instructions.md`, `CODEX.md`, etc.). `AGENTS.md` is a shared convention — one file to describe your project's architecture, conventions, and constraints, read by every major coding agent.

**How it works:**
- Claude Code reads `AGENTS.md` automatically when no `CLAUDE.md` exists in the project
- If both files exist, `CLAUDE.md` takes precedence
- You can change which file Claude Code reads under "Project instructions" in `/config`

**Quick example:**
```markdown
# AGENTS.md

## Architecture
This is a Next.js 14 app with App Router. All pages use server components by default.

## Conventions
- Use `pnpm` for package management
- Tests go in `__tests__/` directories adjacent to source files
- Run `pnpm typecheck && pnpm test` before committing

## Constraints
- Never modify files in `src/generated/` — they are auto-generated from the OpenAPI spec
- Database migrations must be backwards-compatible
```

This is especially useful for open-source projects and monorepos where contributors use different coding agents. One file covers everyone.
