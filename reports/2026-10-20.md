## Featured: `anthropic-skills:computer-use` (Computer Use Skill)

The Computer Use skill lets Claude Code take control of your desktop — viewing your screen, clicking, typing, scrolling, and switching between applications. Available in Claude Code Desktop for Pro and Max subscribers.

**Why it's useful:** When no API, MCP connector, or CLI can reach the app you need, Computer Use is the fallback. Ideal for:
- Testing UI changes in apps without automated test frameworks
- Filling out forms or navigating legacy desktop software
- Automating repetitive multi-app workflows (copy from app A, paste into app B)

**Quick usage:**
```
# In Claude Code Desktop, just ask:
"Open the Figma file and screenshot the header component"
"Fill in the expense report form in SAP with these values: ..."
"Navigate to Settings > Preferences and toggle dark mode"
```

The skill activates automatically when Claude determines no connector covers the target app. It asks for per-app permission and per-action approval for safety. Anthropic advises starting with low-stakes tasks — current reliability is roughly 50% on complex multi-step workflows, but it handles simple repetitive desktop tasks well.
