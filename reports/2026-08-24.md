## Featured: `/design` Skill (Visual Artboard Design from CLI)

The `/design` skill (research preview, launched Aug 17) brings Claude Design's artboard workflow into the terminal and Desktop app, built on Artifacts.

**What it does:** Run `/design` with a brief and Claude publishes a canvas of editable UI artboards. Pick one, tweak text, spacing, and colors inline, then say "implement option 2" and Claude writes the code — all in the same session. No export-paste loop.

**Why it's useful:** If your project has design tokens or a theme file referenced in `CLAUDE.md`, `/design` respects them so drafts match your product's visual identity out of the box.

**Quick example:**
```
/design three layout options for a settings page with sidebar nav
```

Claude publishes three artboards as an Artifact. Click any element to adjust, then ask Claude to implement your pick.

Available on Pro, Max, Team, and Enterprise. Requires v2.1.233+.
