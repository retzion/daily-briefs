## Featured: MCP Background Tasks (v2.1.319)

Starting in v2.1.319, Claude Code automatically backgrounds MCP task operations. When an MCP server returns a task handle instead of an immediate result, Claude Code moves the operation to the background and continues working on other things. The result is picked up when the task completes, just like other background work.

**Why it matters:** Long-running MCP operations (CI triggers, deployments, database migrations) previously blocked the session. Now they run concurrently, making multi-step workflows significantly faster.

**Usage:**
```
# Works automatically — no config needed.
# MCP servers that support the tasks protocol get backgrounded.

# To disable (e.g., for debugging):
export CLAUDE_CODE_DISABLE_MCP_TASK_BACKGROUND=1
```

**Tip:** Combine with the `Monitor` tool for streaming output from background MCP tasks while continuing other work in the same session.
