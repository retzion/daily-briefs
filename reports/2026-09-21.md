## Featured: On-Demand Conversation Compaction (Messages API)

The Messages API now supports [on-demand conversation compaction](https://platform.claude.com/docs/en/build-with-claude/compaction) via the `compact-2026-09-04` beta header. This lets you control when long conversations are summarized rather than relying on automatic truncation.

**Why it matters:** Long-running agentic sessions accumulate context that eventually hits token limits. Previously you either managed this yourself or let the system auto-compact at unpredictable moments. Now you choose when to compact, preserving recent turns verbatim while summarizing older ones.

**How it works:**
```python
response = client.messages.create(
    model="claude-sonnet-5",
    max_tokens=1024,
    betas=["compact-2026-09-04"],
    messages=messages,
    compact=True  # triggers compaction
)
# Returns a signed compaction block — send it as the
# first message in subsequent requests to replace the
# compacted messages. Keep recent turns after it.
```

**Use cases:** Agent loops that run for hours, customer support threads, iterative code review sessions — anywhere you need long context without paying full token costs on every turn.
