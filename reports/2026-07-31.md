## Featured: `DirectoryAdded` Hook

New in Claude Code v2.1.219, the `DirectoryAdded` hook fires whenever a directory is added to your session — via `/add-dir` in the CLI or `register_repo_root` in the SDK.

**Why it's useful**: Automate per-project setup when switching between repos in a single session. Load project-specific MCP servers, adjust permissions, run install scripts, or configure environment variables — all triggered automatically when a new directory enters scope.

**Quick setup** (in `.claude/settings.json`):
```json
{
  "hooks": {
    "DirectoryAdded": [
      {
        "matcher": "",
        "hooks": [
          {
            "type": "command",
            "command": "echo 'Setting up project...' && cd \"$(cat /dev/stdin | jq -r .directory)\" && npm install"
          }
        ]
      }
    ]
  }
}
```

The hook receives a JSON payload on stdin with the `directory` path, letting you branch setup logic per project. Pair with Session Start Hooks for fully automated multi-repo workflows.
