## Featured: `/import-memory` Skill

**What it is:** A built-in Claude Code skill that imports memory exports from other AI assistants (ChatGPT, Copilot, Gemini, etc.) into Claude's memory system. It treats the imported content as data — conversationally and additively — so nothing is blindly overwritten.

**Why it's useful:** Developers switching between AI assistants accumulate context, preferences, and project knowledge that would otherwise be lost. This skill lets you carry forward coding conventions, project context, and personal preferences without manually re-teaching Claude.

**Usage:**
```
/import-memory
```
Then paste or point to your exported memory file. Claude will parse it, deduplicate against existing memories, and add relevant entries. Works with ChatGPT's memory export JSON, Copilot's instruction files, and plain-text preference dumps.
