## Featured: Keyless Console Sign-In (`/login` Console Auth)

As of v2.1.245 (Aug 25), Claude Code supports signing in directly through your Anthropic Console account — no API key required. This is especially useful for enterprise teams whose security policies prohibit creating or distributing API keys.

**How to use it:**
1. Run `/login` in Claude Code
2. Select "Anthropic Console" as the provider
3. Choose "Sign in with your Console account" (recommended)
4. Complete the browser-based OAuth flow

Previously, all Claude Code authentication required creating an API key in the Console and pasting it into the CLI. The new keyless flow uses OAuth, meaning credentials are never exposed in plaintext and can be centrally managed/revoked by org admins. It also integrates with existing Console SSO configurations, so teams using SAML or OIDC for Console access get Claude Code authentication for free.
