## Featured: Send-Now Key (`Ctrl+Enter`)

When Claude Code is working on a task, anything you type and press Enter gets **queued** — it doesn't interrupt. Messages stack up and fire in order when the current turn ends. But sometimes you need Claude to read your input *now* — to steer it, cancel a direction, or provide a missing detail.

**v2.1.275 adds the send-now key**: press `Ctrl+Enter` (or `Ctrl+X Ctrl+S`) to interrupt the current turn and flush all queued messages immediately. Queued and sent messages appear in gray until the model receives them.

**When to use it:**
- Claude is heading down the wrong path and you want to redirect immediately
- You queued a message but realized it needs to go now, not after the current turn
- You have context Claude needs before it finishes its current step

**Quick example:**
```
# Claude is running a long test suite...
# You type: "Skip the integration tests, just run unit tests"
# Press Ctrl+Enter → Claude receives your message immediately
#   instead of waiting for the full test suite to finish
```

This pairs with the existing queue mechanics: `↑` to edit your last queued message, and the gray message indicator showing what's pending. The send-now key fills the gap between "wait patiently" and "Ctrl+C to hard-cancel."
