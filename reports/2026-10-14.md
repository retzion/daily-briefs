## Featured: Idle Compaction (`idleCompaction`)
New in v2.1.299, **idle compaction** automatically compacts your conversation context when two conditions are met: (1) the conversation exceeds 200K tokens, and (2) the session has been idle for approximately 54 minutes. This prevents long-running cloud sessions and background agents from silently hitting context limits during periods of inactivity.

**Why it matters:** Cloud sessions, routines, and PR-watching agents can sit idle for hours between events. Without compaction, the next wake-up may fail or lose early context. Idle compaction handles this transparently.

**Configuration:**
```bash
# Raise the token threshold before idle compaction kicks in
export CLAUDE_CODE_IDLE_COMPACT_MIN_TOKENS=300000

# Disable entirely (e.g., for sessions you want to preserve full context)
# In settings.json:
{ "idleCompaction": false }
```

No action needed for most users — it's on by default and the defaults are sensible. Particularly valuable for scheduled routines and long-lived PR watchers.
