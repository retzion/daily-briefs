## Featured: `bashOutputMaxChars` / `taskOutputMaxChars` Settings
New in v2.1.261, these settings control how much Bash command and background-task output Claude receives inline before it gets saved to a file. The previous limit was low, meaning long build logs or test output were often written to a file and had to be read back — adding latency and losing context.

**Why it matters:** If you work with verbose test suites, build systems, or log-heavy commands, raising these limits keeps the output in Claude's conversation context, leading to faster diagnosis and fewer round-trips.

**Usage:** Add to your project or user settings:
```json
{
  "bashOutputMaxChars": 65536,
  "taskOutputMaxChars": 65536
}
```
Maximum is 128K characters (131072) for each. Start with 64K and adjust — higher values consume more context window but give Claude full visibility into command output.
