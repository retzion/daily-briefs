## Featured: Artifact Inline Edits (`edits` on Publish)

**What it is:** The Artifact tool's `edits` parameter lets you make small changes to a published artifact and redeploy it in a single tool call — no separate Read → Edit → Publish pipeline required.

**Why it matters:** When iterating on a published page, the typical flow is: read the file, edit it, then publish. For small tweaks — fixing a typo, changing a color, updating a data value — that's three tool calls and three round-trips. The `edits` parameter collapses this to one: you send old_str/new_str pairs directly on the publish call. The file is updated on disk and the artifact is redeployed atomically. If any edit doesn't match, nothing changes — it's all-or-nothing.

**Usage pattern:**
```
Artifact({
  file_path: "dashboard.html",
  url: "https://claude.ai/artifact/abc123",
  edits: [
    {
      old_str: '<h1>Q3 Results</h1>',
      new_str: '<h1>Q4 Results</h1>'
    },
    {
      old_str: 'revenue: 42',
      new_str: 'revenue: 58'
    }
  ]
})
```

This changes the file and republishes in one step. Useful for routines, scheduled updates, and rapid iteration on live artifacts.
