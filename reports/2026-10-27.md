## Featured: Artifact Multi-File Publishing (`files` parameter)

When building complex artifacts, you're not limited to a single HTML file. The Artifact tool's `files` parameter lets you publish supporting files — CSS, JavaScript, JSON data, images, fonts — alongside your main page.

**Why it's useful:** Instead of inlining thousands of lines of CSS and JS into one HTML file, you can structure artifacts like real web projects with clean separation of concerns. This makes artifacts more maintainable and enables reuse across projects.

**Key capabilities:**
- Publish any web asset type alongside your HTML page
- Files are served at their relative path, referenced naturally from HTML (`<link href="styles.css">`)
- Copy files from other artifacts server-side with `{artifact: "<url>", path: "<path>"}` — no download/re-upload needed
- On updates, only changed files are republished; omitted files are kept, `null` removes one
- Total limit: 255 files and 64MB per publish, up to 511 files and 256MB per version

**Quick example:**
```
Artifact({
  file_path: "dashboard.html",
  files: {
    "styles.css": "src/styles.css",
    "chart.js": "src/chart.js",
    "data.json": "src/data.json"
  },
  icon: "chart",
  description: "Sales dashboard with live charts"
})
```

This is especially powerful when combined with Artifact Types and design systems — you can build and iterate on multi-file web applications entirely from Claude Code sessions.
