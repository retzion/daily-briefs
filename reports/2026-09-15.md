## Featured: `omitClaudeMd` Agent Option

New in v2.1.271, the `omitClaudeMd` option lets you run subagents without any CLAUDE.md files — user, project, or local.

**Why it's useful:** CLAUDE.md files accumulate project-specific instructions, tool permissions, and coding conventions. That context is usually essential, but some subagent tasks actively suffer from it — a clean research agent shouldn't inherit your project's style rules, and a cross-repo code-review agent shouldn't carry one project's conventions into another.

**In agent frontmatter (`.claude/agents/clean-researcher.md`):**
```yaml
---
omitClaudeMd: true
---
Research the topic without project-specific instructions.
```

**In `--agents` JSON:**
```json
{
  "name": "clean-agent",
  "omitClaudeMd": true,
  "prompt": "Analyze this code from first principles."
}
```

This gives you surgical control: most agents inherit your project context, but specific agents run clean when you need an unbiased perspective.
