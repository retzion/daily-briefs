## Featured: `maxProseWidth` Setting

New in Claude Code v2.1.282, `maxProseWidth` caps the character width of Claude's prose output in wide terminals — while tables, code blocks, and diffs still use the full terminal width.

**Why it matters:** On ultrawide or high-resolution monitors, Claude's output can stretch across 200+ columns, making long prose hard to read. This setting brings readable line lengths without sacrificing the wide layout for structured output.

**Usage:**

Add to your settings (project or user level):
```json
{
  "maxProseWidth": 100
}
```

Or set it inline:
```
/config maxProseWidth=100
```

Values are in characters. A good starting point is 80–120 depending on your font size. Set to `0` or remove to disable (full width, the default). Code blocks, tables, and diffs are never capped — only narrative text wraps at the limit.
