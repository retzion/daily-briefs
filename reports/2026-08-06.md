## Featured: `/teleport` (Cloud-to-Local Session Handoff)

New in v2.1.223, `/teleport` bridges cloud and local Claude Code sessions. When working in a cloud session on claude.ai/code, you'll now see a hint showing how to continue that exact session locally in your terminal.

**Why it's useful:** Cloud sessions are great for kicking off work from your phone or a browser, but sometimes you need local tools, your own shell environment, or to work offline. `/teleport` lets you seamlessly pick up where the cloud session left off — full conversation context, file state, and task progress carry over.

**How to use it:**
```bash
# In a cloud session, run /teleport to see the session ID
# Then in your local terminal:
claude --teleport <session-id>

# The local session resumes with full context from the cloud run
```

This pairs well with Claude Code Routines — you can set up a scheduled cloud task, then teleport into it locally if you need to intervene or continue the work hands-on.
