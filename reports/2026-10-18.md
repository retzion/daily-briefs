## Featured: `waitOnRateLimit` Setting (Unattended Rate-Limit Retry)

When running Claude Code unattended — routines, CI pipelines, background agents — hitting an API rate limit used to mean a hard failure. The `waitOnRateLimit` setting (added in v2.1.300, with `/config` toggle in v2.1.302) tells Claude Code to automatically wait and retry when it encounters rate limits instead of erroring out.

**Why it matters:** Scheduled routines, CI/CD pipelines, and long-running background agents can now survive transient rate limits without manual intervention or custom retry wrappers.

**Usage:**
```jsonc
// In settings.json
{ "waitOnRateLimit": true }
```
Or toggle it interactively via `/config` in any session.

When enabled, Claude Code pauses at a rate limit, waits for the window to reset, and resumes automatically. Especially useful for overnight batch operations and multi-agent workflows where several sessions may compete for quota.
