## Featured: SearchMcpRegistry (In-Session MCP Server Discovery)

Claude Code includes a `SearchMcpRegistry` tool that lets you search the public MCP server registry — now over 9,400 servers — without leaving your session. Instead of manually browsing GitHub repos or the registry website, you can ask Claude Code to find an MCP server for your use case and it will search, suggest, and help you configure it.

**Why it's useful:** The MCP ecosystem has exploded in 2026, but discovery remains a pain point. Having registry search built into your coding session means you can go from "I need a Postgres MCP server" to a configured `.mcp.json` entry in one conversation turn.

**Quick usage example:**
```
You: "I need to connect to my Postgres database from this session"

Claude Code will:
1. Search the MCP registry for Postgres-compatible servers
2. Present options with descriptions and install instructions  
3. Help you add the chosen server to .mcp.json
4. Verify the connection works
```

You can also use the companion tools `SuggestConnectors` and `ListConnectors` to see what's already available or get recommendations based on your current project context.

**Pro tip:** The practitioner consensus in 2026 is to run many Skills but few MCP servers — a five-server MCP setup can cost 50k+ tokens upfront, so be selective. Pin one MCP per external system (GitHub, Postgres, Linear, Sentry) and write thin Skills that orchestrate them.
