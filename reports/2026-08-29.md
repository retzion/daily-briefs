## Featured: `experimental.cacheTtl` (Per-Agent Prompt Cache TTL)

When building custom agent types in `.claude/agents/`, you can now set `experimental.cacheTtl` in the YAML frontmatter to control how long the prompt cache lives for that specific agent. This is useful when different agents have different cost/latency tradeoffs — a quick lookup agent might use `"5m"` to save on cache costs, while a long-running review agent benefits from `"1h"` to avoid re-processing large contexts.

**Usage** — in your agent's `.md` file frontmatter:

```yaml
---
name: my-reviewer
model: opus
experimental.cacheTtl: "1h"
---
Review the PR for correctness bugs...
```

Values: `"5m"` (5-minute TTL) or `"1h"` (1-hour TTL). The setting applies when no subagent TTL is configured at the session level. This shipped in v2.1.248 (Aug 27).
