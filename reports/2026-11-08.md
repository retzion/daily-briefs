## Featured: MCP Resource Browsing

Claude Code can **browse and read data** exposed by connected MCP servers through the Resources protocol, using three dedicated tools: `ListMcpResourcesTool`, `ReadMcpResourceTool`, and `ReadMcpResourceDirTool`.

**What it is:** MCP servers can expose not just tools (actions) and prompts (templates), but also *resources* — structured data identified by URIs like `db://tables/users`, `file://config.yaml`, or `git://repo/tree`. Resources are the read-only data layer of MCP.

**Why it's useful:** Instead of calling a server's tool to fetch data (which may require specific parameters you don't know), you can browse what's available and read it directly. This is especially powerful with database, documentation, or configuration MCP servers — you can explore schemas, read docs, or inspect settings before writing any code.

**Quick usage example:**
```
# In a Claude Code session with a database MCP server connected:

# 1. List available resources
> ListMcpResourcesTool
# Returns: db://tables, db://views, db://schemas/public

# 2. Browse a resource directory
> ReadMcpResourceDirTool uri="db://tables"
# Returns: db://tables/users, db://tables/orders, db://tables/products

# 3. Read a specific resource
> ReadMcpResourceTool uri="db://tables/users"
# Returns: column definitions, constraints, indexes for the users table
```

Resources complement tools and prompts to give Claude a complete picture of what an MCP server offers, without trial-and-error tool calls.
