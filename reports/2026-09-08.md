## Featured: `ant apply` (Declarative Agent Resource Management)

Version 1.30.0 of the `ant` CLI introduces `ant apply`, a Terraform-style command that creates and updates Claude API resources — agents, environments, skills, memory stores, and deployments — from files in your repository.

**Why it matters:** Instead of manually creating agents through the console or imperative API calls, you describe each resource in a Markdown, YAML, or JSON file (frontmatter holds config, body holds the system prompt), run `ant apply`, review and approve the plan, then commit the generated `claude-lock.json`. Next run updates existing resources instead of creating duplicates.

**Quick usage:**
```bash
# Define an agent in agents/support-bot.md
cat > agents/support-bot.md << 'EOF'
---
type: agent
model: claude-sonnet-5
max_tokens: 4096
tools:
  - search_docs
  - create_ticket
---
You are a customer support agent. Answer questions using the docs search tool.
Escalate billing issues by creating a ticket.
EOF

# Apply all resource files
ant apply

# Review the plan, approve, commit the lock file
git add claude-lock.json agents/
git commit -m "Add support-bot agent"
```

Two hashes in the lock file fingerprint what was last sent and what the API returned, so drift from local edits or console changes is detected loudly on the next run. Works alongside Claude Code — Claude Code can shell out to `ant` and reason over the structured output.
