## Featured: `sandbox.network.strictAllowlist` Setting

New in Claude Code v2.1.219, this setting gives you strict network control over sandboxed commands. When enabled, any network request to a host **not** on your explicit allowlist is silently denied — no permission prompt, no fallback.

**Why it's useful**: The default sandbox behavior prompts you when a command tries to reach an unknown host. `strictAllowlist` flips this to deny-by-default, ensuring only pre-approved domains are reachable. Valuable for CI pipelines and enterprise environments where network egress must be tightly controlled.

**Usage** — add to `.claude/settings.json`:
```json
{
  "sandbox": {
    "network": {
      "strictAllowlist": true,
      "allowlist": [
        "registry.npmjs.org",
        "github.com",
        "api.anthropic.com"
      ]
    }
  }
}
```
Any sandboxed command reaching a host not in `allowlist` is blocked without prompting.
