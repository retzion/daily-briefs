## Featured: Managed Agents GitHub Skill Loading

Claude Managed Agents — the cloud-hosted sessions accessible via the Anthropic API — can now **automatically discover and load skills from a mounted GitHub repository**. Any skills placed in the repo's `.claude/skills/` directory are picked up at session start without manual configuration.

**Why it matters:** Teams building on Managed Agents previously had to attach skills individually through the agent's `skills` array in API calls. Now you can version-control your skills alongside your code, and every cloud session that mounts the repo gets them automatically. This is especially powerful for standardizing workflows across a team — deploy review checklists, coding conventions, or domain-specific procedures as skills, and every Managed Agent session inherits them.

**How to use it:**

1. Create `.claude/skills/my-skill/SKILL.md` in your repo
2. Mount the repo when creating a Managed Agent session:
   ```json
   {
     "resources": [{
       "type": "github_repository",
       "repo": "org/repo",
       "token": "ghp_..."
     }]
   }
   ```
3. Skills are discovered automatically — no `skills` array needed

Skills loaded this way follow the same format as local Claude Code skills: a `SKILL.md` file with instructions, optional supporting scripts, and trigger conditions.
