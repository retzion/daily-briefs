## Featured: Artifact Preflight Scripts (`preflight.js`)

When publishing multi-file artifacts with the Artifact tool, you can include a special `preflight.js` file at the artifact root. This script runs automatically against any open browser tabs viewing the artifact whenever Claude publishes an update — enabling live-reload, migration, or graceful transition logic.

**What it is:** A JavaScript module (max 8 KiB) whose default export is a function. It executes in the viewer's browser before the updated page loads, allowing you to clean up state, migrate localStorage, or show a transition.

**Why it's useful:** For interactive artifacts (dashboards, tools, collaborative pages), updates can break in-flight state. Preflight scripts let you handle version transitions gracefully — clearing stale caches, migrating data formats, or notifying viewers that a new version is loading.

**Quick example:**
```javascript
// preflight.js — clear stale chart cache on update
export default function preflight() {
  try {
    const version = localStorage.getItem('app-version');
    if (version && version !== '2.0') {
      localStorage.removeItem('chart-cache');
      localStorage.setItem('app-version', '2.0');
    }
  } catch (e) {
    // localStorage may not be available
  }
}
```

Publish it alongside your artifact files:
```javascript
Artifact({
  file_path: "dashboard.html",
  files: {
    "preflight.js": "preflight.js",
    "styles.css": "styles.css"
  }
})
```

**Constraints:** Must be at the artifact root path, must be a JS module with a default export function, and must stay under 8 KiB. If it doesn't meet these requirements, the publish is refused.
