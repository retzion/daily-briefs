## Featured: `CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH`

A new environment variable in Claude Code v2.1.280 that overrides the default 2,048-character limit on MCP tool descriptions and server instructions.

**Why it matters:** Many MCP servers — especially those wrapping complex APIs like databases, cloud providers, or domain-specific platforms — ship tool descriptions that exceed 2,048 characters. When truncated, the model loses context about parameter semantics, enum values, or usage constraints, leading to malformed tool calls. This variable lets you raise (or lower) the cap per session.

**Usage:**
```bash
# Raise to 8K for a verbose MCP server
CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH=8192 claude

# Or set it in your shell profile
export CLAUDE_CODE_MAX_MCP_DESCRIPTION_LENGTH=8192
```

**Trade-off:** Longer descriptions consume more of your prompt cache budget. Start with the default and only raise it if you see tool-call errors that trace back to truncated descriptions.
