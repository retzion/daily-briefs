## Featured: Claude Fable 5.2

Anthropic's newest frontier model, released November 9, is purpose-built for extended agentic work. It's the first Claude model Anthropic says can "work for days with limited supervision" and coordinate hundreds of subagents.

**Why it matters for Claude Code users:**
- On FrontierCode 2.0, Fable 5.2 scores 49.1% at xhigh effort — up from 32.4% for Fable 5.1 and beating Opus 5.5's 45.5%
- At high effort it matches Opus 5.5's max-effort score (45.3% vs 45.5%) at roughly half the cost per task
- Sonar's Java evaluation: 90.26%, topping their leaderboard
- 55% fewer safeguard false-positives than Fable 5.1

**Quick usage:**
```bash
# Set as default model in Claude Code
claude config set model claude-fable-5-2

# Or use per-session
claude --model claude-fable-5-2

# In Claude Code settings for subagents
claude config set subagentModel claude-fable-5-2
```

**Trade-off:** Fable 5.2 uses more reasoning tokens and costs 37.5% more than Fable 5 per benchmark run. For routine tasks where Opus already meets the bar, Opus remains the more cost-effective daily driver. Reserve Fable 5.2 for complex multi-step work, long-running agents, and hard coding problems.
