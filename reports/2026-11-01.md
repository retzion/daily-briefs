## Featured: `claude auth` (CLI Authentication Subcommands)

The `claude auth` family of subcommands, added in recent releases, streamlines authentication management directly from the CLI — no more hunting for browser flows or wondering if your session is still valid.

**What it is:** Three subcommands under `claude auth`:
- `claude auth login` — authenticate via subscription (default) or API console (`--console`). Accepts a pasted OAuth code when the browser callback can't reach localhost.
- `claude auth status` — check if you're logged in. Exits 0 when authenticated, 1 when not. Use `--text` for human-readable output.
- `claude auth logout` — sign out cleanly.

**Why it's useful:** Essential for CI/CD pipelines, cloud sessions, and headless environments where browser-based auth is awkward. The exit codes make it scriptable:

```bash
# Check auth before running a headless task
if claude auth status; then
  claude -p "Run the test suite and report results"
else
  echo "Not authenticated — run 'claude auth login'"
  exit 1
fi
```

**Flags:** `--email` to pre-fill your address, `--sso` to force SSO, `--console` for API-billed auth.
