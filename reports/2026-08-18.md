## Featured: Subagent Forking (`subagent_type: "fork"`)

As of v2.1.232 (Aug 13), subagent forking is **on by default** in Claude Code. A forked subagent inherits the parent session's full conversation history and prompt cache — no re-briefing required.

**Why it matters:** Traditional subagents start cold. You write a long prompt explaining the codebase, what you've tried, and what you need. A fork already knows all of that. This is ideal for:
- Splitting work mid-task ("you handle the tests, I'll do the migration")
- Getting a second opinion without losing context
- Delegating a subtask that needs the full picture

**Usage:**
```
Agent({
  subagent_type: "fork",
  prompt: "Refactor the auth module to use the new token format we discussed"
})
```

The fork picks up your entire conversation. It shares the prompt cache, so it's faster and cheaper than a fresh agent. Unlike `/branch` (which forks the session for the user), `fork` is a programmatic subagent delegation that returns a result to the parent.

**Tip:** Forks always inherit the parent model — you can't override it with `model:`. If you need a different model, use a regular subagent instead.
