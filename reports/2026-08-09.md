## Featured: Inference Hooks (Enterprise Inline DLP)

Launched August 5 in beta, **inference hooks** give Enterprise compliance teams real-time data loss prevention across every Claude surface — chat, Claude Code, Cowork, desktop, and CLI — with a single org-level setting.

**How it works:** Before any prompt reaches Claude, Anthropic sends a signed HTTPS POST with the conversation transcript to your organization's DLP/security server. The server returns `allow` or `deny` within a 5-second timeout. If denied, Claude never sees the prompt.

**Why it matters:** Until now, enterprises had to rely on network-level proxies or post-hoc audit logs to enforce data policies on AI tools. Inference hooks move enforcement inline — the model literally cannot process a prompt your policy rejects. This works across all surfaces with no per-tool configuration.

**Setup:**
```
# Configured in the Claude Enterprise admin console
# Point to your DLP endpoint (Netskope, Palo Alto, Zscaler, or custom)
Inference Hook URL: https://dlp.yourcompany.com/claude/inspect
Timeout: 5000ms
Failure mode: deny  # block if DLP server is unreachable
```

**Limitations:** Verdicts are binary allow/deny — prompt rewriting or redaction is not supported. The 5-second timeout means your DLP server needs to be fast.

**Blog:** [Inference hooks: inline data loss prevention for Claude Enterprise](https://claude.com/blog/claude-enterprise-inference-hooks)
