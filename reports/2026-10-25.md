## Featured: `Explore` Agent Type

The `Explore` agent is a built-in Claude Code agent type optimized for fast, read-only code search. Instead of doing the work yourself — grepping, globbing, reading files, adjusting search terms — you hand the question to an Explore agent and get an answer back without cluttering your main context with intermediate search results.

**Why it's useful:** Code exploration is one of the most common tasks in agentic coding, but each search round adds tool output to your context window. The Explore agent runs in a subagent with its own context, so your main session stays clean. It's also tuned for search: it uses Glob, Grep, Read, and web tools but cannot edit files, making it safe by design.

**Quick example:**
```
> Where is the authentication middleware defined and which routes use it?

Claude spawns: Agent({
  subagent_type: "Explore",
  prompt: "Find where auth middleware is defined and list all routes that use it",
  description: "Find auth middleware"
})
```

You can control search depth with a breadth hint: `"quick"` for a single targeted lookup, `"medium"` for moderate exploration, or `"very thorough"` to search across multiple locations and naming conventions. Best for "where is X?", "which files reference Y?", and symbol lookups — not for code review or cross-file analysis that requires reading entire files.
