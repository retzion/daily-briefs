## Featured: "Concise" Output Style

Shipped today in v2.1.237, "Concise" is a new built-in output style that changes how Claude Code communicates during a session. Instead of narrating its thought process and explaining each step, Claude leads with results and skips preamble — while doing the work just as thoroughly under the hood.

**Why it matters:** Power users have long wanted Claude Code to "just do the thing" without the running commentary. The Concise style delivers exactly that — fewer words, same quality. It's especially useful for experienced developers who don't need step-by-step explanations, or for sessions where you're chaining many tasks and want minimal noise.

**How to use it:**
```
/config
→ Output style → Concise
```

You can switch back to the default "Normal" style anytime. The setting persists across sessions. This is different from custom system prompts or CLAUDE.md instructions — it's a first-class, optimized behavior mode built into the harness.
