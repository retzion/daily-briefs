## Featured: Artifact Types & Quickstart

When creating artifacts in Claude Code (shareable web pages, slide decks, documents, visual designs), the **Quickstart** action streamlines the process by matching your intent to pre-made artifact types with integrated design systems.

**Why it matters:** Instead of writing an HTML page from scratch, you can create a professional slide deck, styled document, or visual design from a template. The type handles layout, theming, dark mode, and responsive design — you supply only the content.

**Usage:**
```
# In a Claude Code session, just ask naturally:
"Create a slide deck summarizing our Q3 metrics"
"Make a design mockup for the new settings page"
"Write up a document explaining our migration plan"

# Behind the scenes, Claude calls Artifact quickstart:
Artifact({ action: "quickstart", intent: "slides" })
# → Returns the matching type, design systems, and fill instructions
# → You publish to a private URL, shareable with one click
```

**Intents:** `slides` (decks), `document` (text to read/edit together), `design` (visual prototypes on a canvas), `other` (anything else). Design systems are automatically attached for slides and designs. The resulting artifact downloads as .pptx or PDF for decks, so no separate file-export step is needed.
