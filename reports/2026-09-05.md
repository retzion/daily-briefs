## Featured: /skill-doctor

`/skill-doctor` is a new slash command added in Claude Code v2.1.261 (September 4, 2026) that audits your loaded skills and identifies which ones are unused and how much context window they consume.

**Why it's useful:** Skills load instructions into your context window, consuming tokens on every turn. Over time, projects accumulate skills that were useful once but no longer match current workflows. `/skill-doctor` finds these dead-weight skills so you can unload them, freeing context budget for actual work.

**Usage:**
```
/skill-doctor
```

Run it in any session to get a report listing each loaded skill, whether it was invoked during the session, and its approximate token cost. Remove unused skills from your project's `.claude/settings.json` or personal config to reclaim context. Especially valuable in large projects with many plugins and team-shared skill sets.
