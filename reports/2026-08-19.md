## Featured: Artifact Comment Threads

Published Claude Code Artifacts support **threaded comments** — viewers can leave feedback anchored to specific elements, and Claude can read, reply to, and resolve those threads programmatically. This turns artifacts into async review surfaces for team deliverables.

**How it works:**

1. A viewer leaves a comment on a published artifact and mentions `@claude` (or activates Claude via the thread's control)
2. Claude reads threads with `action: "comments"` on the artifact URL
3. Claude replies with `action: "reply"` — posts appear as "Claude · via the user"
4. After addressing feedback, Claude marks threads resolved with `action: "resolve"`

**Why it's useful:** Instead of copying artifact content into a separate review tool, teams can iterate directly on the published page. Claude watches for activated threads and can autonomously address feedback — fix a chart, update copy, adjust styling — then resolve the thread. It's particularly powerful with scheduled routines: a daily report artifact can accumulate stakeholder comments overnight, and a morning routine can triage and address them.

**Quick example (in a Claude Code session):**
```
# Read all comment threads on an artifact
Artifact({ action: "comments", url: "https://claude.ai/artifacts/abc123" })

# Reply to a specific thread
Artifact({ action: "reply", url: "https://claude.ai/artifacts/abc123",
           thread_id: "thread_xyz", text: "Fixed — updated the chart colors." })

# Mark the thread resolved
Artifact({ action: "resolve", url: "https://claude.ai/artifacts/abc123",
           thread_id: "thread_xyz" })
```
