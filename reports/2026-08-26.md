## Featured: `modelPicker` Setting

New in v2.1.243, `modelPicker` lets you curate the `/model` picker with your own ordered, labeled list of models — including Vertex AI and AWS Bedrock model IDs.

**Why it's useful:** Teams using custom gateways, Bedrock cross-region inference, or contracted model access often need specific model ID spellings (e.g., `us.anthropic.claude-sonnet-5-v2:0`) that aren't in the built-in picker. `modelPicker` puts them front-and-center with human-readable labels.

**Quick setup** (in `.claude/settings.json` or user settings):
```json
{
  "modelPicker": [
    {
      "model": "us.anthropic.claude-opus-4-6-20250610:0",
      "name": "Opus 4.6 (Bedrock)",
      "description": "US East cross-region"
    },
    {
      "model": "claude-sonnet-5-20260620",
      "name": "Sonnet 5 (API)"
    }
  ]
}
```
Models appear after the built-in entries. Omit `name` to default to the model ID; omit `description` to get "Custom model (\<id\>)". ([Claude Code Docs](https://code.claude.com/docs/en/model-config))
