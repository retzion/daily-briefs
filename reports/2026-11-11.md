## Featured: `anthropic-skills:chrome-browser` (Chrome Browser Skill)

Claude Code cloud sessions come with Chromium and Playwright pre-installed — but the **Chrome Browser skill** is what teaches Claude Code to use them effectively for real browser automation during coding sessions.

**Why it matters:** Unlike the simpler built-in browser skill (which handles basic page fetches), the Chrome Browser skill enables full interactive browser sessions: navigating multi-page flows, filling forms, clicking buttons, waiting for dynamic content, and taking screenshots at any point. This is essential for verifying UI changes, running E2E test scenarios, debugging frontend issues, or scraping data from authenticated web apps.

**Key capabilities:**
- Full Playwright-powered Chromium automation (pre-installed, no setup)
- Navigate pages, interact with elements, handle JavaScript-rendered content
- Take screenshots for visual verification (device scale factor 2 for user-facing shots)
- Device emulation for mobile/tablet testing

**Quick usage:**
```
# Just invoke the skill — Claude Code handles the rest:
/chrome-browser

# Or ask Claude Code to use the browser naturally:
"Open localhost:3000, log in with test credentials, navigate to the
 settings page, and screenshot the result"

# The skill uses the pre-installed Chromium at /opt/pw-browsers/chromium
# No 'playwright install' needed — it's already there
```

This skill pairs well with the `/run` skill: launch your dev server, then use Chrome Browser to verify changes visually — all without leaving your Claude Code session.
