## Featured: Agent Tool `effort` Parameter (Per-Subagent Effort Control)

When spawning subagents with the Agent tool, you can now pass an `effort` parameter to control how much reasoning the subagent uses — independent of the session-wide effort level.

**Why it matters:** Not every subagent task needs deep reasoning. A quick file lookup can run at `low` effort (fast, cheap), while a complex code review might warrant `high` or `max`. With Haiku 5.5 now supporting effort levels — a first for any Haiku model — this becomes especially powerful for cost optimization.

**Usage example:**
```
Agent({
  description: "Quick file lookup",
  prompt: "Find where AuthService is defined",
  effort: "low"
})

Agent({
  description: "Deep security audit",
  prompt: "Review auth flow for injection vulnerabilities",
  effort: "max"
})
```

**Key detail:** The `effort` parameter should only be set when explicitly requested by the user, a CLAUDE.md rule, or a skill — the agent otherwise runs at its default effort. This prevents accidental over- or under-reasoning.
