## Featured: `pipeline()` Workflow Function
The `pipeline()` function in Claude Code Workflows enables streaming multi-stage orchestration where each item flows through stages independently — maximizing parallelism by starting stage 2 for item 1 while item 2 is still in stage 1.

**Why it's useful**: Traditional `parallel()` + sequential chaining waits for all items to complete a stage before moving to the next. `pipeline()` removes that bottleneck, cutting wall-clock time significantly for review, verification, and processing workflows.

**Quick example** — review files across dimensions, verify each finding as soon as its review completes:
```js
const results = await pipeline(
  DIMENSIONS,
  d => agent(d.prompt, { label: `review:${d.key}`, phase: 'Review' }),
  review => parallel(
    review.findings.map(f => () =>
      agent(`Verify: ${f.title}`, { label: `verify:${f.file}`, phase: 'Verify' })
        .then(v => ({ ...f, verdict: v }))
    )
  )
);
```

Each dimension's findings start verifying the moment that dimension's review finishes — no wasted time waiting for other dimensions to complete.
