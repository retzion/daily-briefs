## Featured: `/insights` Command (Session Analytics Report)

The `/insights` slash command analyzes your last 30 days of local Claude Code sessions and generates an interactive HTML report — a personal retrospective on how you actually use the tool.

**Why it's useful:** Most developers build habits and friction patterns they don't notice. `/insights` surfaces them: what's working, where you hit walls, which workflows are ambitious, and where quick wins exist.

**What it reports:**
- Stats dashboard (session count, token usage, tool call patterns)
- "At a Glance" summary: working style, friction points, quick wins
- Usage charts and trend analysis
- Narrative analysis of your working patterns over time

**Usage:**
```
/insights
```

The report is saved to `~/.claude/usage-data/report.html` and opens in your browser. All analysis runs locally on your session transcripts — no data is sent to Anthropic.

**Tip:** Run it monthly to spot evolving patterns. If you notice you're spending disproportionate time on permission prompts, that's a signal to run `/fewer-permission-prompts`.
