## Featured: Auto Mode on Third-Party Providers

Starting with Claude Code v2.1.328, **auto mode** — the permission system that lets Claude decide which tool calls are safe to run without asking — now works on Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry, and the Claude apps gateway. Previously, auto mode only worked with direct Anthropic API connections.

**Why it matters:** Enterprise teams that route Claude Code through their own cloud provider can now use auto mode instead of manually approving every tool call. This was a top-requested feature for teams using Bedrock or Vertex, where the constant approval prompts slowed down agentic workflows.

**What changed:**
- Interactive sessions with no explicit permission mode now **start in auto mode by default**
- Auto mode covers Opus 4.6 and Sonnet 4.6 on all supported providers
- The built-in classifier fallback was removed (v2.1.321) — calls the server can't check are either prompted or denied via `permissions.denyInsteadOfPrompting`

**Quick setup:** If you're on Bedrock/Vertex/Foundry and previously had to use `allowedTools` workarounds, just upgrade to v2.1.328+. Auto mode will be your default. To opt out:

```json
// .claude/settings.json
{
  "permissions": {
    "defaultMode": "normal"
  }
}
```
