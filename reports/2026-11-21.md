## Featured: Workflow `args` Global (Parameterized Workflows)

The `args` global in the Workflow tool lets you pass structured input into a workflow script, making workflows reusable across different contexts. Instead of hardcoding file lists, queries, or config into the script, you pass them as `args` and the script reads them as a global variable.

**Why it's useful**: A single workflow script can handle different inputs — review different file sets, run searches with different queries, or process different repos — without editing the script each time.

**Quick example**:

```javascript
export const meta = {
  name: 'review-files',
  description: 'Review specified files across dimensions',
  phases: [{ title: 'Review' }],
}

// args is a global, passed from the Workflow tool call
const results = await parallel(
  args.files.map(f => () =>
    agent(`Review ${f} for correctness and style issues`, {
      label: `review:${f}`,
      phase: 'Review'
    })
  )
)
return { results }
```

Invoke with:
```
Workflow({ script: "...", args: { files: ["src/auth.ts", "src/api.ts", "src/db.ts"] } })
```

**Tip**: Pass arrays/objects as actual JSON values in `args`, not as JSON-encoded strings — a stringified array breaks `args.map()` in the script. The `args` global is available immediately, no imports needed.
