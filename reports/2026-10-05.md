## Featured: Claude for Government (GA)

Anthropic's **Claude for Government** reached general availability on September 30, making Claude Code and Cowork the first major agentic coding tools available in a FedRAMP High authorized environment for U.S. federal and state agencies.

**Why it matters:** Government developers have been largely locked out of the agentic coding revolution due to compliance requirements. This deployment brings the full Claude Code experience — terminal agent, cloud sessions, mods — into regulated environments with purpose-built governance controls.

**Key capabilities:**
- **Department-level administration** — Admins set configuration defaults, model access, and spending caps per department or group
- **Audit logs** — All administrative actions are logged to support the agency ATO (Authority to Operate) process; sensitive operations require two-person approval on Anthropic's end
- **Local conversation history** — Conversations stay on the agency-managed device, not in the cloud
- **SSO & SCIM** — Single sign-on through the agency's own identity provider with SCIM group mappings that control rate limits, dollar caps, and allowed models per seat tier

**Quick start:** Agencies can request access through [claude.com/government](https://claude.com) and set up SSO via the self-serve admin portal.
