## Featured: "You Should Know" Built-In Mod

The "You Should Know" mod is Claude Code's first built-in mod, shipped Oct 1 with v2.1.287. It runs a lightweight side agent alongside your main session that watches for things you or Claude might be missing during longer tasks — overlooked edge cases, implicit assumptions, or context that slipped out of the window.

**Why it's useful:** During complex multi-file changes, it's easy for both the developer and the agent to lose track of subtle details. This mod acts as a second pair of eyes without requiring you to set up a separate review workflow.

**How to enable:**
```
/plugin enable cc-plugin-you-should-know@builtin
```

When it spots something, it displays a note above the prompt. As of v2.1.288, these notes use clearer language ("we decided," "the main agent changed," "you asked for") to distinguish between your decisions and Claude's.

**Availability:** First-party sessions with telemetry enabled. Disabled by default — you opt in.
