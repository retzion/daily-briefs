## Featured: `--restricted` Mode
New in v2.1.248, `--restricted` is a CLI flag for running Claude Code in a locked-down, security-first configuration. It removes all built-in command and code execution tools (Bash, etc.), constrains file tools to the working directory, refuses `bypassPermissions`, strips WebFetch, and ignores user/project/local settings files.

**Why it matters:** Enterprise and CI/CD environments need to run Claude Code without risk of arbitrary command execution or settings injection. `--restricted` makes Claude Code safe to embed in automated pipelines, review bots, and sandboxed environments where you want file analysis and code generation without execution capabilities.

**Usage:**
```bash
# Run Claude Code in restricted mode
claude --restricted

# Combine with other flags for CI pipelines
claude --restricted -p "Review this diff for security issues" < diff.patch

# In a Docker container or sandbox
claude --restricted --model claude-opus-4-6 -p "Analyze src/ for type errors"
```

Restricted mode pairs well with the existing `--safe-mode` flag (which skips plugins and hooks) but goes further by removing execution tools entirely.
