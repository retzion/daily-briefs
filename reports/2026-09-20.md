## Featured: Claude Code Projects (Beta)

Claude Code's redesigned **Projects** feature (Sept 17) turns a single project conversation into a coordinator that manages parallel cloud sessions.

**What it is:** You describe a goal in a project conversation, and Claude breaks it into tasks, spawns parallel threads (each a full cloud session on its own branch), coordinates them, reviews outputs, and assembles the result. Threads share project memory and a library of uploaded files and generated artifacts.

**Why it's useful:** For multi-repo or multi-concern work — shipping a feature that touches frontend, backend, and infra — Projects eliminates the serial bottleneck of one-thread-at-a-time. Instead of manually context-switching between sessions, Claude orchestrates the fan-out and merge.

**Quick usage:**
1. Open Claude Code on the web or desktop → create a new Project
2. Describe your goal: *"Add OAuth2 login — update the API, React frontend, and Terraform config"*
3. Claude scopes the work, spins up parallel threads, and keeps you updated
4. Review assembled results; threads share memory so later work builds on earlier decisions

**Access:** Beta for select Pro/Max subscribers using cloud sessions. Expanding to more Claude Code users, then Team/Enterprise.
