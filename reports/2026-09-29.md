## Featured: Claude Mods (TypeScript Function Hooks)

Claude Mods is a new experimental extension mechanism that lets you customize Claude Code's interface and behavior using TypeScript function hooks. Unlike plugins (which package MCP tools, skills, and agents), Mods hook directly into Claude Code's rendering and interaction pipeline — think browser extensions but for your terminal coding agent.

**Why it's useful:** Mods unlock customizations that weren't possible before — redacting sensitive data in output, rendering Mermaid diagrams inline in the terminal, creating custom diff views, or adding keyboard shortcuts. The community response has been explosive, with developers sharing creative mods within days of launch.

**Quick start:**
```bash
# Enable the experimental feature
export CLAUDE_CODE_ENABLE_FUNCTION_HOOKS=1

# Mods are TypeScript files in ~/.claude/mods/
# Example: a mod that highlights TODO comments in output
// ~/.claude/mods/highlight-todos.ts
export default {
  name: "highlight-todos",
  hook: "MessageDisplay",
  transform(message: string) {
    return message.replace(/TODO:/g, "\x1b[33mTODO:\x1b[0m");
  }
};
```
