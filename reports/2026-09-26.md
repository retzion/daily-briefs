## Featured: `claude remote-control` (Remote Control from Phone)

Start a Claude Code session on any machine — from your phone.

**What it is:** Running `claude remote-control` on a machine (your workstation, a dev server, a cloud VM) registers it as a device card in the Code tab of the Claude app on iOS/Android and at claude.ai/code. Tap the card, pick a directory, and a full Claude Code session starts on that machine — your phone is just a window into it.

**Why it's useful:** You're at lunch and realize you forgot to kick off a migration. Pull out your phone, tap your office machine, and start the session. The code runs on your machine, with your filesystem and credentials — your phone is the remote.

**Quick setup:**
```bash
# On the machine you want to control
claude remote-control

# That's it — the machine appears as a device card in:
#   - Claude app (iOS / Android) → Code tab
#   - claude.ai/code → device cards at top
```

**Key details:**
- Sessions run locally on the target machine — nothing leaves it except the conversation
- Dropped connections auto-recover across wifi/network changes
- Out of research preview as of August 2026
- Works alongside `/teleport` (cloud-to-local handoff) and cross-session messaging

[Docs](https://code.claude.com/docs/en/remote-control)
