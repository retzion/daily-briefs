## Featured: `CLAUDE_CODE_TOOL_MEMORY_LIMIT` (Bash Tool Memory Capping)

Claude Code v2.1.233 introduces **memory cgroup support** for Bash tool commands on Linux. Set the `CLAUDE_CODE_TOOL_MEMORY_LIMIT` environment variable to cap how much memory any single Bash tool invocation can consume.

**Why it matters:** Anyone who's had Claude Code kick off a `npm install`, `cargo build`, or `webpack` that ate all available RAM knows the pain. The process balloons, your system freezes or OOM-kills other work, and the session may not recover gracefully. Memory capping gives you a safety net — the command is killed before it takes down the machine.

**Quick usage:**
```bash
# Cap each Bash tool command at 4GB
export CLAUDE_CODE_TOOL_MEMORY_LIMIT=4g

# Or set it in your Claude Code settings
claude config set env.CLAUDE_CODE_TOOL_MEMORY_LIMIT 4g
```

When a command exceeds the limit, it's terminated with an OOM signal. Claude sees the failure and can retry with a lighter approach (e.g., building fewer packages at once).

**Best for:** Self-hosted runners, CI environments, shared dev servers, or any machine where runaway builds are a recurring problem.
