## Featured: `NotebookEdit` Tool

The `NotebookEdit` tool lets Claude Code edit Jupyter notebooks (`.ipynb` files) cell by cell — adding, removing, replacing, or reordering cells without breaking notebook metadata or output state. This is especially useful because notebooks are JSON under the hood, and raw file edits often corrupt them.

**Why it's useful:** Data scientists and ML engineers live in notebooks. `NotebookEdit` means you can ask Claude Code to add a visualization cell, fix a data processing step, or insert markdown documentation into a notebook, and it handles the structural JSON correctly. It also preserves existing cell outputs, so you don't lose rendered charts or computed results.

**Quick example:**
```
> Add a cell after cell 3 that plots the loss curve using matplotlib

Claude uses NotebookEdit to insert a new code cell at position 4:
  import matplotlib.pyplot as plt
  plt.plot(history['loss'], label='train')
  plt.plot(history['val_loss'], label='val')
  plt.legend()
  plt.title('Training Loss')
  plt.show()
```

The tool supports `insert_before`, `insert_after`, `replace`, and `delete` operations, and you can target cells by index. It's available as a deferred tool — Claude Code loads it automatically when working with `.ipynb` files.
