## Featured: Workflow Resume (`resumeFromRunId`)

When running multi-agent Workflow scripts in Claude Code, iterations are common — you run a workflow, review the results, tweak the script, and run again. Without resume, every re-run re-executes all agent calls from scratch, burning tokens and wall-clock time.

**What it is:** The `resumeFromRunId` parameter on the Workflow tool lets you resume a workflow from a prior run. Completed `agent()` calls whose prompt and options haven't changed return their cached results instantly — only edited or new calls re-execute.

**Why it's useful:** If you have a 12-agent review workflow and only need to change the final synthesis prompt, resume replays the first 11 agents from cache in seconds and only runs the updated 12th. This saves significant tokens and time during iterative development.

**Usage example:**
```
// First run returns a runId in its result, e.g. "wf_abc123"
// After editing the script file:
Workflow({
  scriptPath: "/path/to/my-workflow.js",
  resumeFromRunId: "wf_abc123"
})
```

The longest unchanged prefix of `agent()` calls returns cached results; the first changed call and everything after runs live. Same script + same args = 100% cache hit. You can also read `<transcriptDir>/journal.jsonl` to inspect each agent's actual return value from a prior run.

**Tip:** Pair with `Edit` to tweak a single stage of a persisted workflow script, then resume — this turns multi-agent orchestration into a rapid iteration loop rather than an all-or-nothing batch job.
